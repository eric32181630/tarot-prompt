# 🔮 Tarot Prompt - Cyber Tarot Divination Web App

An elegant, pure front-end Tarot divination web application designed to bridge modern large language models (LLMs) with mysticism. It allows users to draw cards based on their life queries, optionally integrate their birth chart parameters for higher context accuracy, and instantly serialize everything into a highly structured, optimized prompt for deep AI interpretation.

🌐 **Live Demo**: [tarotprompt.netlify.app](https://tarotprompt.netlify.app/)

---

## ✨ Key Features

- **One-Click Prompt Engineering**: Automatically compiles your question, card array, positions (upright/reversed), and cosmological data into a beautifully structured prompt optimized for advanced LLMs.
- **Astrological Integration (Optional)**: Users can input key birth chart parameters (such as Sun, Moon, Ascendant, or Venus signs) to provide the AI with deeper user context for a more tailored reading.
- **100% Privacy-Focused**: Built entirely on the client side with **NO backend database**. All inputs, logs, and divination history are stored strictly within the user's browser memory (`localStorage`). Your personal reflections and data never leave your device.
- **Mystic UI/UX Experience**: Features a fluid, responsive, and aesthetically pleasing mystic theme, complete with a local "Divination Log" modal to review current session queries.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Custom Properties & Responsive Layouts), Vanilla JavaScript (ES6+)
- **Storage**: Web Storage API (`localStorage`)
- **Deployment**: Hosted on Netlify
